# Imagens originais — artigos sobre manetes

Estas cinco imagens foram geradas especificamente para o projeto Grid do Autorama em 16/10/2026 com a ferramenta integrada OpenAI ImageGen. Não foram usadas fotografias de terceiros nem imagens de referência. Os originais PNG permanecem na pasta de imagens geradas do Codex; estes WebP são versões recortadas para 16:9 e otimizadas para o site.

A geração por IA, por si só, não garante ausência de risco jurídico. As imagens evitam marcas e logotipos identificáveis; antes de qualquer uso comercial, revise cada arquivo e os termos aplicáveis.
